# Clinexa Serenity
## Folder System Specification — v1.0

Status: APPROVED BASELINE
Source: Clinexa Serenity Visual Master Board v1.0
Design Direction: Serenity

---

## 1. Purpose

The Clinexa folder system provides semantic visual organization without becoming decorative noise.

Folders should help the user identify context quickly.

The system must remain:

- calm
- professional
- consistent
- semantic
- recognizable
- scalable

---

## 2. Core Principle

All folders belong to one visual family.

The base folder must remain consistent.

Semantic meaning is expressed through:

- accent color
- badge
- small internal symbol
- restrained surface variation

The folder silhouette itself should not change randomly.

---

## 3. Base Geometry

The base folder should use:

- soft geometric construction
- moderate corner radius
- clear tab silhouette
- balanced visual weight
- strong readability at 22–48 px

The shape should feel modern but not playful.

Avoid:

- cartoon folder shapes
- exaggerated tabs
- sharp industrial geometry
- excessive depth

---

## 4. Base Material

Preferred material:

Deep Graphite / Deep Navy

Reference tones:

- #0C1422
- #111B2A
- #172235

The folder body should feel:

- stable
- premium
- calm
- durable

---

## 5. Lighting

Folder lighting follows the main Clinexa icon grammar.

Preferred:

- subtle upper-left highlight
- restrained vertical tonal transition
- low-contrast bottom shadow
- mild edge definition

Avoid:

- glossy plastic
- strong specular highlights
- permanent glow
- neon outlines

---

## 6. Depth

Folders use Soft Depth.

Depth should come from:

- tonal separation
- subtle overlap
- controlled shadow
- restrained highlight

Avoid:

- bevel-heavy 3D
- deep extrusion
- floating-card appearance

---

## 7. Semantic Folder Categories

Core categories:

- Home
- Clinical
- Research
- Education
- Projects
- Documents
- Downloads
- System
- Media

Additional folders may be added later only if they follow the same system.

---

## 8. Semantic Accent Mapping

| Folder | Accent | Meaning |
|---|---|---|
| Home | Clinical Blue | Primary workspace |
| Clinical | Teal | Clinical work / stability |
| Research | Violet | Research / advanced knowledge |
| Education | Cyan | Learning / information |
| Projects | Clinical Blue | Production / active work |
| Documents | Neutral + Cyan | General information |
| Downloads | Cyan / Teal | Incoming content |
| System | Slate / Blue | System / technical |
| Media | Contextual restrained accent | Visual/audio content |

---

## 9. Accent Rule

Accent colors should occupy a minority of the folder.

Preferred use:

- badge
- tab detail
- small stripe
- compact emblem
- subtle internal mark

Avoid:

- recoloring the entire folder
- rainbow collections
- high-saturation folder bodies

---

## 10. Badge System

Badges may indicate folder meaning.

Examples:

Clinical:
cross-like abstract health mark, not a hospital cross

Research:
structured knowledge / node symbol

Education:
book / learning symbol

Projects:
modular block / build symbol

Documents:
document sheet

Downloads:
downward transfer symbol

System:
gear / technical mark

Media:
media symbol

Badges must remain simple.

---

## 11. Medical Symbol Rule

Clinical folders must avoid:

- oversized medical cross
- ECG line as the primary identity
- stethoscope illustration
- hospital building symbols

Preferred approach:

abstract care / clinical symbol language.

---

## 12. Folder Identity

A user should identify the semantic category before reading the label.

However, category recognition must not depend on color alone.

Use:

- badge
- geometry
- label
- accent

together.

---

## 13. Folder States

Required states:

- Default
- Hover
- Selected
- Open
- Active / highlighted
- Disabled where relevant

State changes should preserve semantic identity.

---

## 14. Hover

Hover behavior:

- slight brightness increase
- subtle accent visibility increase
- minimal elevation change

Avoid dramatic animation.

---

## 15. Selected State

Selected folder state should use:

- Clinical Blue or Calm Cyan context
- increased surface contrast
- subtle border or glow if necessary

Selection must remain clearly distinguishable.

---

## 16. Open Folder

Open state should feel related to the closed form.

Do not redesign the folder entirely.

Use:

- changed tab/open geometry
- slightly increased internal visibility
- same semantic accent

---

## 17. Small-Size Strategy

Required review sizes:

16 px
22 px
24 px
32 px
48 px
64 px
128 px
256 px

At small sizes:

- badge may simplify
- fine highlights may disappear
- tab geometry must remain clear
- semantic accent must remain readable

---

## 18. Place Icons

Place icons and folder icons should feel related.

Examples:

- Home
- Documents
- Downloads
- Pictures
- Music
- Videos
- Network
- Trash
- Devices

Places may use stronger symbolic identity than generic folders.

---

## 19. Home Folder

Home is the primary personal workspace.

Accent:

Clinical Blue

Character:

- calm
- central
- familiar
- not decorative

Avoid using a literal house illustration if it harms coherence.

---

## 28. Visual Family Test

Every folder must be reviewed beside:

- Home
- Clinical
- Research
- Education
- Projects
- Documents
- System

If one folder appears to come from another icon theme, it fails.

---

## 29. Rejection Criteria

Reject a folder if it:

- uses unrelated geometry
- recolors the entire body without purpose
- feels cartoonish
- becomes neon-heavy
- loses readability at 32 px
- relies only on color
- uses excessive medical symbolism
- breaks the Serenity palette
- becomes visually louder than application icons

---

## 30. Production Rule

Correct production order:

Base Folder
→ Core Semantic Variants
→ State Variants
→ Small-Size Review
→ Approval
→ Expansion

Do not create a large folder collection before the base family is approved.

---

## 31. Final Principle

Clinexa folders should organize the workspace visually without demanding attention.

They should feel familiar, semantic, and calm.
